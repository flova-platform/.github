## About

Flova is an IoT platform for connecting devices, collecting data, and building applications around connected hardware.

It provides the cloud services and tools needed to manage IoT projects, from small experiments to production systems.

---

## Platform

### 🔌 Devices

Connect hardware devices and communicate with them through Flova.

### ☁️ Cloud

Manage devices, data, and IoT projects from one place.

### 🛠 Tools

Use APIs, SDKs, and developer tools to build your own connected solutions.

### 📊 Applications

Create dashboards and interfaces for monitoring and controlling devices.
